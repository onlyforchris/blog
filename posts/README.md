# posts —— 文章目录

这里存放 Blog 的独立技术文章。每篇文章是一个 Markdown 文件，遵循下面的约定。

## 约定

- 一篇文章一个 `.md` 文件，文件名用中文标题的简洁形式（不携带空格），或能一眼看出主题的英文短名；建议与文章标题一致。
- 文章顶部用一段简单的前言（frontmatter）标注元信息，方便以后接入静态站点：
  ```yaml
  ---
  title: 文章标题
  date: 2026-09-01
  tags: [主标签, 副标签]
  ---
  ```
- 正文以 `# 文章标题` 开头，用 `##` / `###` 分节。
- 风格：写真实工程问题与可复用的结论，不做工具清单和概念拼盘；如果某处细节不确定，就写“以实际项目为准”，不编造数值、版本或链接。
- 涉及具体仓库的案例，引用真实存在的仓库与 Release，除非明确说明，否则不虚构具体版本号。
